# sirtai

CLI for [SIRT.ai](https://sirt.ai) — External memory for AI.

## Quick Start

```bash
npx sirtai init
```

## Commands

| Command | Description |
|---------|------------|
| `sirt init` | Setup connection & account |
| `sirt stats` | Brain statistics |
| `sirt search <query>` | Keyword search |
| `sirt semantic <query>` | Semantic search |
| `sirt get <id>` | Get a node |
| `sirt save <id>` | Save/update a node |
| `sirt me` | Current user info |
| `sirt status` | E2E encryption status |
| `sirt unlock` | Unlock E2E encryption |
| `sirt lock` | Lock E2E encryption |
